# Historic Eden Cemetery — Deliverables

Deliverables from the brand narrative work 1838 Black Metropolis carried out for Historic Eden Cemetery: brand narrative, walking tour, and technical architecture.

Live: https://1838blackmetropolis.github.io/Eden-Presentation/

## What's here
- `index.html` — front page: welcome, links to every document, the Google Drive review folder, Lot Data, the lot map, and the Eden website.
- `brand-narrative.html` — Brand Narrative and Awareness Strategy (with Appendix A, the elevator pitches).
- `appendix-b-90-day-plan.html`, `appendix-c-partnership-pathway.html` — the two one-page plans as separate pages.
- `elevator-pitches.html` — Elevator Pitches and Statement of Importance.
- `tour-full.html`, `tour-short.html` — guide scripts for the full (90–120 min) and short (45–60 min) walking tours.
- `technical-architecture.html` — Technical Architecture Recommendation.
- `presentation.html` — the 30-slide walk-through deck (`→` `←` / space · `F` fullscreen · `O` overview · deep-link with `#12`). Images in `assets/`.
- `brand.css`, `logo.jpg` — shared styling and the 1838 roundel.
- `Eden_Cemetery_Brand_Tour_and_Technical_Architecture.pdf` / `.docx` — the combined document.

## Edit
Each document page is self-contained HTML styled by `brand.css`. Each `<section class="slide">` in `presentation.html` is one slide; `data-sec` sets the footer label. The editable sources for the PDF/Word versions live in the project's `source/` folder (not in this repo).
