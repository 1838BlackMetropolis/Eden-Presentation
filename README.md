# Historic Eden Cemetery — Project Walk-Through

Branded HTML slide deck for walking Eden Cemetery through the 1838 Black Metropolis deliverable:
Brand Narrative & Awareness Strategy, Tour, and Technical Architecture.

## Run it
Open `index.html` in a browser, or serve with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## Navigate
`→` `←` / space · `F` fullscreen · `O` overview grid · click right/left half of a slide · deep-link with `#12`

## Edit
Each `<section class="slide">` in `index.html` is one slide; `data-sec` sets the footer label.
Slides 19–24 cover how the tour was built (30 slides total). Slide 18 links to the self-guided tour pages on the website (`tour-long.html`, `tour-short.html`).
Images live in `assets/`.
